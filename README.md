# Building-and-Deploying-Generative-AI-Models-RAG-Notebooks
This is the Github repository of the coding notebooks from the Coursera course **Building and Deploying Generative AI Models** from the specialization *Generative AI Fundamentals* by ***Alberta Machine Intelligence Institute (Amii)***.

This repo contains the coding notebooks for *Module 2* of the course, where you build, refine, and evaluate Retrieval-Augmented Generation (RAG) systems and compare them with fine-tuning approaches.
The notebooks are designed to follow along with the videos, but you can also use them independently to experiment with different RAG techniques.
